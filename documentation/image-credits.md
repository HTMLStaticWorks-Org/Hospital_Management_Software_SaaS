# MediCore HMS — Image Credits & Attribution Manifest

Every photograph in **MediCore HMS** is a high-resolution, real-world clinical, hospital, architectural, or portrait photograph sourced under free commercial license from **Unsplash**.

- **Zero repeated images:** Each image file is used **strictly once** across the entire project (across all 15 marketing pages and 9 admin dashboard pages).
- **Local storage & formats:** Every image is stored locally inside `assets/images/<category>/` in **WebP** (`1200w`/`400w` + `640w` responsive `srcset`) alongside an optimized **JPEG** fallback.
- **No external hotlinks:** Zero external image URLs exist in any HTML, CSS, or JS file.
