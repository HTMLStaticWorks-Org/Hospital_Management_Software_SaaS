01 · QUICKSTART

Getting Started & Tenant Provisioning

Every MediCore HMS hospital tenant receives an isolated FHIR R4 base URL, an MLLP listener endpoint for laboratory/radiology equipment, and a dedicated SAML 2.0 realm.

# Base FHIR R4 Endpoint (Production Cluster)
https://api.medicorehms.com/v4/fhir/{hospital_tenant_id}

# Authenticate with OAuth 2.0 Client Credentials (SMART-on-FHIR)
curl -X POST https://auth.medicorehms.com/oauth2/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&client_id=HOSP_APEX_01&scope=system/Patient.read system/Encounter.write"

03 · REST & FHIR R4 API REFERENCE

Create Inpatient Admission (`POST /Encounter`)

Admits a registered UHID patient into an available ICU or ward bed and automatically locks the bed tile on the real-time ADT board.

POST /v4/fhir/hosp-apex/Encounter HTTP/1.1
Host: api.medicorehms.com
Authorization: Bearer eyJhbGciOiJSUzI1NiIsImtpZCI6Im1jLTIwMjYifQ...
Content-Type: application/fhir+json

{
  "resourceType": "Encounter",
  "status": "in-progress",
  "class": { "system": "http://terminology.hl7.org/CodeSystem/v3-ActCode", "code": "IMP", "display": "inpatient encounter" },
  "subject": { "reference": "Patient/UHID-2026-9041", "display": "Aarav Sharma" },
  "participant": [{ "individual": { "reference": "Practitioner/EMP-101", "display": "Dr. Kabir Sen" } }],
  "location": [{ "location": { "reference": "Location/ICU-A-BED-04", "display": "ICU-A Bed 04" }, "status": "active" }],
  "reasonCode": [{ "coding": [{ "system": "http://id.who.int/icd/release/11/mms", "code": "BA41.0", "display": "Acute STEMI" }] }]
}

05 · SECURITY & RBAC SCOPES

SMART-on-FHIR Scopes & Audit Compliance

All API tokens enforce least-privilege clinical scopes (`patient/*.read`, `user/Observation.write`, `system/Claim.write`). Every request is logged to an immutable WORM audit bucket retained for 10 years under HIPAA §164.312(b).
